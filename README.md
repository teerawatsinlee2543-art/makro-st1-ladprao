# Makro ST 1 ลาดพร้าว — ชุดแอปของสาขา ST 1

ชุดแอป (Makro Finder · Waste O2O · GR พาเลท · Shelf-Life · O2O Scan Logger) ของสาขา **ST 1 ลาดพร้าว**
เริ่มต้นจากสำเนาของชุดแอป Store 42 แต่แยกขาดกัน:

| เรื่อง | ST 1 (หน้านี้) |
|---|---|
| ฐานข้อมูล | Firebase โปรเจกต์ของ ST 1 เอง (`makro-st1-ladprao`, Firestore กรุงเทพ) — ไม่ใช้ร่วมกับสาขาอื่น |
| หน้ารวมแอป | `makro-st1.html` |
| ที่เก็บในเบราว์เซอร์ | ทุกชื่อ localStorage / IndexedDB ขึ้นต้น `st1.` (ไม่ปนกับแอปสาขาอื่นแม้เปิดบนเครื่องเดียวกัน) |

ข้อมูลตั้งต้นถูกก๊อป **ครั้งเดียว** จากสำเนาของฐานข้อมูลสาขาเดิม (2026-11-24) หลังจากนั้นแก้ฝั่งไหน อีกฝั่งไม่เปลี่ยน

## ที่ยังเป็นข้อมูลตั้งต้นของสาขาเดิม (ต้องปรับเป็นของลาดพร้าว)
รายการสินค้า/ตำแหน่ง (`ItemLocation_*.xlsx`), รูปสินค้า, ผังร้าน, พาเลท, ข้อมูล O2O, Shelf-Life, ข้อเสนอแนะลูกค้า และรหัส PIN พนักงานในแอป

## หมายเหตุ
- กติกา Firestore (`firestore.rules`) เปิดให้ทุกคนที่มีลิงก์อ่าน/เขียนข้อมูลได้ (ไม่ต้องล็อกอิน) — ถ้าลิงก์หลุดออกนอกทีม ควรเพิ่มการล็อกอิน
- รหัสสาขาในหัวใบพิมพ์/ลิงก์รายงาน BIP ตั้งเป็น 1 (`001 MAKRO ST0001`, `STORE_ID=1`) — ตรวจให้ตรงกับรหัสจริงของสาขา
